# VOB extraction prompt v2

You are extracting insurance benefits for Applied Behavior Analysis (ABA) services
from a payer eligibility and benefits response.

Return ONLY a JSON object. Each key below maps to an object with:
- `value`: the extracted value, or null if the document does not state it
- `confidence`: your confidence from 0 to 1 that the value is correct
- `quote`: the exact text from the document the value came from (or null)

Value formats:
- money: a number in dollars (25 for "$25.00" or "twenty-five dollars")
- percent: a number (20 for "20%")
- bool: true or false
- int: a whole number
- pos: a list of two-digit place-of-service codes, for example ["11", "12"]
- text: a short string

Rules (new in v2):
1. `sessions_per_year` is the annual visit or session limit. Never use the
   "units per day" cap for it. If no limit is printed for a code, return null
   with low confidence.
2. Telehealth place of service: POS 02 is telehealth outside the home and POS 10
   is telehealth in the member's home. Keep them separate. If the document says
   one is "not covered", do not include it in `allowed_pos`.
3. If a code line does not show a clear copay, use the copay shown in the plan
   summary at the top of the document.
4. If coverage is terminated or inactive, return null for every benefit field.
5. If two lines disagree, prefer the most recent correction and lower your confidence.
